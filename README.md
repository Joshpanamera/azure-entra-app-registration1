# azure-entra-app-registrations
# Azure Cloud Identity & App Registration

## Overview

This project demonstrates the creation and configuration of an application in Microsoft Entra ID (formerly Azure Active Directory).

The purpose of this exercise was to gain hands-on experience with cloud identity management, application registration, authentication concepts, and Azure Active Directory.

## Technologies

- Microsoft Azure
- Microsoft Entra ID
- Azure Active Directory
- OAuth 2.0
- Cloud Identity

## What I Completed

- Created an Azure Free Account
- Created a Microsoft Entra ID Application
- Configured Application Registration
- Explored Client ID and Tenant ID
- Learned authentication concepts
- Explored Azure Portal

## Key Concepts Learned

- Application Registration
- Client ID
- Tenant ID
- Object ID
- OAuth 2.0 Authentication
- Cloud Identity Management
